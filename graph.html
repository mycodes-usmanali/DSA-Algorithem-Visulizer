Prim's Algorithm

O(E log V)

Purpose: Finds the Minimum Spanning Tree (MST)

Approach: Greedy - grows MST from a starting vertex by always adding the cheapest edge to a new vertex.

Use Case: Network design, clustering

Dijkstra's Algorithm

O(E log V)

Purpose: Finds shortest path from source to all vertices

Approach: Greedy - always expands the closest unvisited vertex.

Use Case: GPS navigation, routing protocols

Kruskal's Algorithm

O(E log E)

Purpose: Finds the Minimum Spanning Tree (MST)

Approach: Greedy - sorts all edges and adds them if they don't form a cycle.

Use Case: Network design, image segmentation

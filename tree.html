Binary Search Tree (BST)

Avg: O(log n) | Worst: O(n)

Property: For any node N, values in the left subtree are smaller than N, and values in the right subtree are larger than N.

Traversals: In-order traversal of a BST will always output the node values in sorted ascending order.

Drawback: Inserting values in sorted order (e.g. 1, 2, 3...) results in a linear chain (skewed tree), causing searches to degrade to O(n) time.

AVL Tree (Self-Balancing)

Avg: O(log n) | Worst: O(log n)

Property: An AVL tree is a self-balancing BST. The height difference (balance factor) between left and right subtrees of any node cannot exceed 1.

Balancing: Maintains log n height by executing single or double rotations on insertion and deletion when nodes become unbalanced.

Rotations: Handles Left-Left (LL), Right-Right (RR) single rotations, and Left-Right (LR), Right-Left (RL) double rotations.
